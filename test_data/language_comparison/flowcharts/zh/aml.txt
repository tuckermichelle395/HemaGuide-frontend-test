中文结构化治疗流程图 - AML / APL
来源范围：根据本地 NCCN AML 2026、ELN AML 2022、ELN-DAVID AML MRD 2025、ELN-DAVID FLT3-ITD MRD 2026、中国成人非 APL AML 诊疗指南 2023 内容整理，用于 HemaGuide 本地测试。
注意：这是结构化摘要，不是指南原文，不替代临床决策。

总原则：
- 先确认疾病实体：APL、核心结合因子 AML、FLT3 突变 AML、IDH1/IDH2 突变 AML、治疗相关/MDS 相关 AML、TP53 或复杂核型 AML、复发/难治 AML。
- 先确认阶段：初诊、诱导后残留、完全缓解后巩固、维持、分子复发、形态学复发、移植后复发。
- 先确认适应性：年龄、ECOG、器官功能、感染/出血风险、是否能接受强化治疗、是否有移植供者。
- 如果病例已包含流式、核型/FISH、融合基因和分子检测结果，不要把“立即补做这些检查”作为核心治疗建议。
- 对 AML 治疗建议必须包含：诱导/低强度治疗、缓解后治疗、MRD 监测、移植讨论、支持治疗。
- 对 APL 治疗建议必须优先处理凝血异常和分化综合征风险。
- 风险分层优先综合遗传学、治疗相关/MDS 相关背景、TP53/复杂核型、MRD 动态和患者适应性，而不是只按年龄分层。
- 中国本土场景中，应说明方案需结合药物可及性、医保/院内路径、移植资源和患者意愿。
- 输出语言：最终建议必须使用简体中文。

分支 AML-0：信息整合与风险分层
适用条件：
- 任何 AML/APL 病例进入治疗决策前。
关键判断：
- 形态学、免疫表型、细胞遗传学、融合基因和 NGS 突变是否足以确诊。
- 是否为 PML::RARA 阳性 APL。
- 是否为核心结合因子 AML：RUNX1::RUNX1T1/t(8;21) 或 CBFB::MYH11/inv(16)。
- 是否有 FLT3-ITD、FLT3-TKD、IDH1、IDH2、NPM1、CEBPA bZIP、TP53、KIT、RUNX1、ASXL1、BCOR、EZH2、SF3B1、SRSF2、STAG2、U2AF1、ZRSR2、NUP98、KAT6A::CREBBP 等关键遗传异常。
- 是否存在治疗相关 AML、MDS 相关改变、复杂核型或单体核型。
建议：
- 明确诊断实体、风险层级、治疗阶段和治疗适应性。
- 明确 MRD 标志物，例如 PML::RARA、RUNX1::RUNX1T1、CBFB::MYH11、NPM1 或流式 MRD。
- 有 CEBPA、RUNX1、DDX41、GATA2 等提示胚系易感的线索时，建议区分体细胞突变和胚系易感；这会影响供者选择和家系评估。
- 信息不足时进入 AML-13，不要过度确定治疗。

分支 AML-0A：ELN/中国指南风险分层校准
适用条件：
- 已获得染色体、融合基因和 NGS 结果，需要给出风险分层和移植倾向。
有利风险倾向：
- 核心结合因子 AML：RUNX1::RUNX1T1 或 CBFB::MYH11。
- NPM1 突变且无主导性不良因素。
- CEBPA bZIP 框内突变。
中间风险倾向：
- 不满足有利或不良风险定义的病例。
- 部分 NPM1/FLT3 组合需结合等位基因负荷、共突变、MRD 和采用的指南体系解释。
不良风险倾向：
- TP53 突变、复杂核型或单体核型。
- 治疗相关 AML、MDS 相关遗传异常或继发于 MDS/CMML 的 AML。
- RUNX1、ASXL1、BCOR、EZH2、SF3B1、SRSF2、STAG2、U2AF1、ZRSR2 等 MDS 相关基因突变。
- MECOM、NUP98、KAT6A::CREBBP 等高危重排或指南定义的不良异常。
建议：
- 风险分层用于决定巩固强度、是否早期进入移植评估、MRD 监测频率和复发风险沟通。
- 不同指南体系可能对少数遗传异常归类不同，输出时要说明依据和不确定性。

分支 AML-1：疑似或确诊 APL，初始紧急处理
适用条件：
- PML::RARA/t(15;17) 阳性，或形态学/临床高度怀疑 APL。
建议路径：
- 高度怀疑时立即启动 ATRA，不等待全部检测完成。
- 同步纠正凝血异常：血小板、纤维蛋白原、凝血酶原时间、D-二聚体动态监测和替代治疗。
- 监测和预防分化综合征，必要时使用糖皮质激素。
- 使用 ATO 时监测 QT 间期、电解质、肝功能和药物相互作用。

分支 AML-2：低危 APL
适用条件：
- APL，白细胞负荷较低，无高危白细胞增多特征。
建议路径：
- 首选 ATRA + ATO，可采用每日或间歇 ATO 方案。
- 若 ATO 不可用或禁忌，可考虑 ATRA + idarubicin，或 ATRA + GO。
缓解后：
- 按方案完成巩固治疗。
- 使用 PML::RARA 定量监测 MRD。
- 维持治疗取决于所用方案和 MRD 结果。

分支 AML-3：高危 APL
适用条件：
- APL 伴白细胞负荷高或临床高危表现。
建议路径：
- ATRA + ATO 基础上联合 idarubicin 或 GO。
- 若 ATO 不适合，可考虑 ATRA + daunorubicin + cytarabine，或 ATRA + idarubicin。
- 有明显心脏风险时，优先考虑减少蒽环类暴露的方案，如 ATRA + ATO + GO。
缓解后：
- PML::RARA 定量 MRD 监测。
- MRD 阳性或复发风险高时进入复发/挽救路径。

分支 AML-4：复发 APL
适用条件：
- APL 分子复发或形态学复发。
建议路径：
- ATO ± ATRA ± GO 或蒽环类作为挽救治疗。
- 分子缓解后可考虑自体造血干细胞移植。
- 未能获得分子缓解、早期复发或高危复发时，讨论异基因移植或临床试验。

分支 AML-5：初诊非 APL AML，适合强化治疗，核心结合因子或其他有利风险
适用条件：
- 年龄、ECOG 和器官功能允许强化治疗。
- RUNX1::RUNX1T1/t(8;21)、CBFB::MYH11/inv(16)，或其他有利风险分子特征。
建议路径：
- 标准 7+3 诱导。
- CD33 阳性或核心结合因子 AML 可考虑在合适场景整合 GO。
- 可选强化方案包括 FLAG-IDA + GO 或 FLAG + GO，需结合中心经验和患者耐受性。
缓解后：
- 以中/高剂量 cytarabine 为基础巩固，必要时联合 GO。
- 使用 RUNX1::RUNX1T1、CBFB::MYH11、NPM1 或流式 MRD 监测。
移植：
- 首次完全缓解期是否异基因移植主要由 MRD、复发风险、共突变和患者适应性决定。

分支 AML-6：RUNX1::RUNX1T1/t(8;21) AML，合并 KIT 突变
适用条件：
- t(8;21) 或 RUNX1::RUNX1T1 阳性，可伴 KIT D816V 或其他 KIT 突变。
建议路径：
- 仍按核心结合因子 AML 进行强化诱导和 cytarabine 巩固。
- KIT 突变提示复发风险可能升高，但是否升级治疗应结合 MRD 动态，而不是仅凭 KIT 阳性。
MRD：
- 定量监测 RUNX1::RUNX1T1。
- 若 MRD 下降不理想或持续阳性，讨论强化巩固、移植和临床试验。
- KIT D816V 或较高 VAF 作为复发风险背景，但不应替代 RUNX1::RUNX1T1 MRD 动态。
- 若 MRD 清除良好，首次缓解期治疗仍可按核心结合因子 AML 路径推进。

分支 AML-7：初诊非 APL AML，FLT3 突变，适合强化治疗
适用条件：
- FLT3-ITD 或 FLT3-TKD 阳性。
建议路径：
- 7+3 联合 FLT3 抑制剂。
- FLT3-ITD 可考虑 quizartinib 相关路径；FLT3 突变也可考虑 midostaurin 相关路径。
缓解后：
- cytarabine 巩固联合相应 FLT3 抑制剂。
- 根据 MRD、FLT3 负荷、共突变、供者情况讨论首次缓解期异基因移植。
- 对 FLT3-ITD 阳性病例，应在可行时把 FLT3-ITD 纳入 MRD 评估，而不是只依赖诊断时突变状态。

分支 AML-7A：FLT3-ITD MRD 监测
适用条件：
- FLT3-ITD 阳性 AML 已达到形态学缓解，尤其是接受强化治疗、FLT3 抑制剂、HMA/VEN 或准备移植的患者。
建议路径：
- 使用敏感的 NGS 方法评估 FLT3-ITD MRD；报告时注明检测灵敏度、样本来源和时间点。
- 建议在诱导/巩固后、移植前、移植后随访或治疗结束评估时结合 FLT3-ITD MRD。
- FLT3-ITD MRD 阳性提示复发风险升高，应触发更密集监测、移植评估、FLT3 抑制剂策略或临床试验讨论。
- FLT3-ITD MRD 阴性不等于治愈，仍需结合 NPM1、流式 MRD、细胞遗传学和临床风险。

分支 AML-8：治疗相关 AML、MDS 相关 AML、复杂核型、TP53 突变或不良风险
适用条件：
- 治疗相关 AML、MDS 相关遗传异常、复杂/单体核型、TP53 突变，或由 MDS/CMML 转化。
建议路径：
- 优先临床试验。
- 适合强化治疗且符合适应证时，可考虑 CPX-351。
- 其他可选方案包括标准 7+3、decitabine + venetoclax、azacitidine + venetoclax、CLIA + venetoclax、FLAG-IDA + venetoclax。
缓解后：
- 若获得缓解且患者适合，尽早讨论异基因造血干细胞移植。
- 若无法移植，考虑维持或低强度延续治疗。

分支 AML-9：初诊非 APL AML，不适合强化治疗或拒绝强化治疗
适用条件：
- 高龄、体弱、ECOG 较差、器官功能限制、合并感染或患者拒绝强化治疗。
优先路径：
- azacitidine + venetoclax。
- decitabine + venetoclax。
- IDH1 突变可考虑 azacitidine + ivosidenib。
其他路径：
- oral decitabine/cedazuridine + venetoclax。
- cladribine + LDAC + venetoclax。
- LDAC + venetoclax。
- azacitidine 或 decitabine 单药，适用于不能使用 venetoclax 的患者。
- LDAC + glasdegib。
- FLT3 突变可考虑 gilteritinib ± azacitidine。
- IDH2 突变可考虑 enasidenib ± azacitidine。
监测：
- 早期骨髓评估、感染预防、输血支持、肿瘤溶解综合征和长期细胞减少管理。
- 若 HMA/LDAC + venetoclax 有效，通常持续治疗至进展或不可耐受，并通过减少 venetoclax 天数、延迟周期或调整剂量管理长期细胞减少。
- 老年 AML 不应仅因年龄自动归入姑息治疗；应进行治疗适宜性和共同决策评估。

分支 AML-10：诱导后残留病或诱导失败
适用条件：
- 强化诱导后未达完全缓解，或骨髓仍有明显残留白血病。
建议路径：
- 根据既往诱导方案和患者状态选择再诱导。
- 可考虑 cytarabine 相关方案、标准 7+3 或 5+2、HMA + venetoclax、CPX-351。
- 若获得缓解，尽快讨论异基因移植。

分支 AML-11：完全缓解后的巩固与维持
适用条件：
- AML 达到 CR/CRi/形态学缓解。
巩固路径：
- 中/高剂量 cytarabine ± GO。
- cytarabine + daunorubicin + GO。
- FLT3 突变可用 cytarabine + midostaurin 或 cytarabine + quizartinib。
- CPX-351 诱导者可考虑 CPX-351 巩固。
- 低强度诱导获得缓解者可延续 HMA + venetoclax 或相应低强度方案。
维持路径：
- oral azacitidine。
- 某些场景可考虑 azacitidine、decitabine 或低剂量 decitabine + G-CSF。
- 靶向维持需结合突变、MRD 和移植计划个体化。
- 中国指南语境下，中高危患者若不移植或移植前后需疾病控制，可考虑去甲基化药物维持或桥接策略。
- 缓解后治疗不应因为达到形态学缓解就停止；需要根据 MRD、风险层级和耐受性规划后续治疗。

分支 AML-12：复发或难治非 APL AML
适用条件：
- 原发难治、缓解后复发、HMA/VEN 后复发、移植后复发或分子复发进展。
总体路径：
- 优先临床试验。
- 根据突变谱选择靶向治疗，例如 FLT3、IDH1、IDH2、CD33 等相关策略。
- 目标可以是再次缓解、桥接异基因移植、细胞治疗研究或症状控制。
强化挽救：
- FLAG 或 FLAG-IDA ± venetoclax。
- CLAG 或 CLAG-M。
- etoposide + cytarabine ± mitoxantrone。
- clofarabine ± cytarabine ± idarubicin。
- CLIA + venetoclax。
低强度挽救：
- azacitidine 或 decitabine。
- azacitidine/decitabine + venetoclax。
- LDAC + venetoclax。
移植后复发：
- 评估减停免疫抑制、供者淋巴细胞输注、低强度治疗、靶向治疗、临床试验和二次移植可能性。

分支 AML-12A：中国复发难治场景的输出原则
适用条件：
- 病例问题询问复发难治 AML 的治疗选择，或患者已有多线治疗失败。
建议路径：
- 明确复发类型：原发难治、早期复发、晚期复发、分子复发、移植后复发、HMA/VEN 后复发。
- 优先重做或复核遗传学和靶点信息，尤其 FLT3、IDH1、IDH2、NPM1、TP53、CD33 和可用于 MRD 的标志物。
- 若有可靶向突变，优先讨论靶向药或临床试验作为桥接移植或疾病控制。
- 若无靶向机会，结合体能和既往方案选择强化挽救或低强度挽救。
- 输出中应说明目标是治愈性桥接、再次缓解、延长生存还是症状控制。

分支 AML-13：信息不足或结论矛盾
适用条件：
- 缺少年龄/ECOG/器官功能、诊断实体不清、治疗阶段不清、分子结果缺失或 MICM 结果互相矛盾。
建议路径：
- 明确列出缺失信息。
- 只给出条件性建议，不给出过度确定的治疗方案。
- 若关键检测已经在报告中出现，不要重复要求“立即完善”同一检测。

分支 AML-14：AML MRD 总流程
适用条件：
- AML 达到形态学缓解、准备巩固/维持/移植、或需要判断复发风险。
MRD 方法：
- 分子 MRD：优先用于有稳定分子标志物的病例，例如 NPM1、RUNX1::RUNX1T1、CBFB::MYH11、PML::RARA、FLT3-ITD 等。
- 多参数流式 MRD：适用于缺少稳定分子标志物或需要补充评估的病例。
- NGS MRD：可用于特定突变，但 DTA 类克隆性造血相关突变不应单独作为白血病 MRD 判断依据。
时间点：
- 诱导后、巩固期间、巩固结束、移植前、移植后和随访中按风险分层监测。
- 移植后第一年可强化流式 MRD 评估；分子或高灵敏 NGS MRD 可延长到移植后 24 个月左右。
临床解释：
- MRD 阳性或转阳提示复发风险升高，应讨论治疗强化、移植、靶向治疗、临床试验或更密集监测。
- MRD 阴性表示低于检测阈值，不等于没有残留白血病；仍需结合遗传学风险和治疗计划。
- MRD 结论必须同时说明方法、样本、时间点、阈值和检测灵敏度。

分支 AML-15：中国成人非 APL AML 路径校准
适用条件：
- 中国本地成人非 APL AML 病例，需要输出符合国内临床表达习惯的建议。
诊断检查：
- 病史中关注既往 MDS/MPN、治疗相关性、重要脏器功能、髓外浸润、家族史和胚系易感线索。
- 检查中包括形态学、免疫分型、核型/FISH、融合基因、NGS 突变、出凝血、血生化和 HLA 配型。
治疗分层：
- 治疗选择应从“能否耐受强化治疗”出发，而不是单纯按年龄。
- 可耐受强化治疗者，基础诱导可采用 7+3 或国内常用 IA/DA/含 HHT/中剂量 cytarabine 方案，并按突变整合靶向药。
- 不耐受强化治疗者，优先考虑 HMA/LDAC + venetoclax、HMA 单药、LDAC 相关方案或靶向药组合。
疗效评价：
- 诱导后骨髓评估用于判断残留病和下一步治疗。
- CR/CRi 后必须规划巩固、维持、MRD 监测和移植评估。
移植：
- 中高危、MRD 持续阳性、MRD 转阳或诱导反应差者，应早期进入异基因移植讨论。
- 有移植意愿或可能者，尽早完成 HLA 配型和供者评估。
